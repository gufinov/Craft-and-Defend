# P3H.4 — hinge-based held tools, measured icon regions and masonry skins

## Outcome

Apply Tony's 2026-09-18 playtest corrections without changing combat reach, timing or placement authority. Held tools hinge at the hand and strike toward the crosshair; every item icon is centred in its card at one visual size; ammunition renders at item scale with no neighbouring fragment; placed Furnace and Tower Platform carry a masonry skin.

## Owner model for held tools

Treat the item art as a square. Its bottom-left corner is the hand. Tools are drawn from that corner toward the top-right (north-east). The corner is the hinge: a strike rotates the whole square counter-clockwise about it so the head sweeps left toward the crosshair, then returns. The hinge sits in the lower-right of the view with the handle at the screen base.

## Runtime contract

- `game/data/item_atlas_regions.json` is the authority for where each item's art is inside `item_atlas_p3h2.png` and `ammunition_atlas_p3h3.png`. It is generated by `python tools/measure_item_atlas.py` (Pillow required) as the tight bounds of the dominant opaque object (α > 128) in each nominal cell; slivers and drop shadows that cross a cell edge are excluded by keeping the longest occupied column run, then row run. Re-run the tool after replacing an atlas. `tests/test_item_atlas_regions.py` validates the file without Pillow.
- `ItemIconCatalog.region_for(item_id)` returns the measured region; `region_for_index` remains only as the nominal-grid fallback and for diagnostics. Card textures pad the measured object to a centred square (`CARD_FRAME_SCALE`) so every icon reads at one size; first-person references use the tight region.
- `HeldItemView` owns a hinge node in the lower-right of the view. The sprite's bottom-left corner sits on the hinge; sprite height is normalised to `TOOL_HEIGHT` for raised tools and `LOW_HEIGHT` for everything else, so atlases of different resolution share one scale. Hinge X is a fraction of the visible half-width clamped to `[HINGE_RIGHT_MIN, HINGE_RIGHT_MAX]` so the swing still reaches toward the crosshair on ultrawide displays; tools use `TOOL_HINGE_DOWN_FRACTION` (handle at the base) and low-held items `LOW_HINGE_DOWN_FRACTION` (above the hotbar, as accepted in P3H.2). A strike rotates the hinge by `TOOL_SWING_ARC_RADIANS` counter-clockwise and returns; low-held items keep the placement nudge. No mirroring: the art already points north-east.
- The placed Furnace visual is Castle Stone masonry with a stepped dark arch and an emissive ember bed; Tower Platform parts use the Castle Stone texture. Occupancy, support, mount sockets and collision are unchanged.
- `ContentRegistry.balance_*` accessors declare their intermediate as `Variant` so the pinned editor's warnings-as-errors setting no longer blocks headless editor runs; behaviour is unchanged.

## Owner correction round 2 (2026-09-18, ultrawide playtest)

- The hand sat about one block too far right on the 3440×1440 display. `HINGE_RIGHT_FRACTION`/`MIN`/`MAX` moved from 0.58/0.50/0.95 to 0.48/0.45/0.78, which places the hand roughly one hotbar slot further inward at both 16:9 and 21:9.
- The Tab inventory did not conform to the Field Build / Workbench inventory tiles: its slots were stretched into wide strips with a separate slot-label row that starved the icon. `InventoryItemSlot` now shares `CraftingItemSlot`'s anatomy (large centred icon, count in the corner, one `slot · name` caption; the active hotbar marker colours the caption) and `app.gd` lays the 18 carried and 9 hotbar tiles out at a fixed `INVENTORY_TILE_SIZE` with no horizontal stretch, left-aligned under the filter row.

## Owner correction round 3 (2026-09-18): strike is a keyframed path

Rotating the sprite about the hinge cannot read as a strike. The hit is still logged at the crosshair; the animation now follows `TOOL_SWING_KEYS`: snap toward the crosshair but stop short of it (view stays clear), whip down-left and vanish behind the hotbar left of centre, rise back to rest. Keys are fractions of the visible half-extents so the path scales with aspect ratio. T104 renders four panels (ready, strike, whip, Furnace).
