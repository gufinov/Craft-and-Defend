CRAFT AND DEFEND — PORTABLE WINDOWS BUILD

Keep these files together in one folder:
  START_GAME.cmd
  CraftAndDefend.exe
  CraftAndDefend.pck
  build_manifest.json

Double-click START_GAME.cmd (or CraftAndDefend.exe) to play. Godot Editor is not required.

Saved games and global settings:
  %APPDATA%\CraftAndDefend\

In-game screenshots (default F2; editable in Keybinds):
  %APPDATA%\CraftAndDefend\screenshots\

Windows Print Screen remains available for Snipping Tool. It is separate from the in-game capture action.
